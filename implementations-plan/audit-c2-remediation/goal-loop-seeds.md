# /goal and /loop seed strings — audit-c2-remediation

Two alternatives for the autonomous implementation session. **They don't compose** — set ONE per Claude Code session. Prefer `/goal` (the completion condition is transcript-observable: test exit codes, the ASCII phase checklist, the codex verdict). Use `/loop` (self-paced) if you want per-turn babysitting instead.

## /goal (primary)
```
/goal All phases P0–P8 marked ✓ in the ASCII checklist at the top of each update; per-phase lessons logged in implementations-plan/audit-c2-remediation/lessons/phase-N.md. The 9 fixes are done, each with a test that PROVES it in the transcript: W1 signs from the out-of-band immutable snapshot with reject-on-post-review-mismatch (firmware-native harness shows the reject SW) + reveal #N folded; W5 Schnorr secret temporaries scrubbed (parity green, -Oz asm checked); W2 deploy review renders sponsor 8+6 + selector and the host fails closed if a supplied sponsor ≠ the single manifest source; W3 root barrel no longer exports signOuterHash/loadCachedSecret (API-shape test) ; W4 GET_AZTEC_ADDRESS round-trip green (device-displayed 8+6 == returned == host oracle) AND AztecLedgerSession.connect() rejects when host-derived ≠ device-attested; W6 docs/UI state the single-seed model; W7 each APPEND_CALL reject arm asserts its exact SW (0x6F09/0A/0B/0C) and device sigs assert s<=half_n + secp.verify (closes AHW-087). ## /loop (fallback, self-paced)
```
```
/loop Each turn, in priority order: 1) State check — read the ASCII phase checklist from the latest update, `git status`, and (if a PR exists) `gh pr checks --watch`. 2) If CI/tests in flight, stream and wait. 3) If a check or local run failed, triage + fix; call `/codex xhigh` on any non-obvious or architectural call (esp. W4 capability/no-fallback, W1 snapshot storage); commit small + conventional + signed. 4) If the in-flight phase is green (firmware builds via docker ledger-app-builder-lite; Speculos green on a clean port; `bun run lint:all` + `bun test packages/` exit 0; phase tests assert their real proof), mark it ✓, write implementations-plan/audit-c2-remediation/lessons/phase-N.md, advance to the next pending phase (P0→P8). 5) If nothing is in flight, pick the next pending phase from plan.md and execute (edit → build/lint/test → commit → push → watch). Discipline: never reuse MANIFEST_VERSION for W4; never let the host fall back to a host-derived receive address; W1 must sign from the snapshot; keep the ASCII checklist at the top of every update; never merge to main or release branches; PR for owner review. Continue until P0–P8 ✓, lint+tests green, post-impl codex review folded, and the PR is open for the owner.
```

## Notes
- `<test>` = `bun test packages/`; `<lint>` = `bun run lint:all`. Firmware: docker `ledger-app-builder-lite` build + `ghcr.io/ledgerhq/speculos` on a CLEAN port (NOT the orphaned :5001).
- W1's reject-on-mismatch branch is NOT honestly black-box Speculos-testable — the `/goal` references the firmware-native harness for that specific proof.
- The PR is for owner review; do not merge without approval (the owner merges).
